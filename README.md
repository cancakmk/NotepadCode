# Notepad Code 📓

> A minimalist, theme-adaptive monochrome notebook and page organizer for **VS Code**, **Cursor**, **Windsurf**, and **Google Antigravity** — powered by zero-config multi-IDE Model Context Protocol (MCP) and GitHub Copilot integration.

---

## ✨ Key Features

- 🌐 **Global Storage Across All Workspaces:** Regardless of which folder, project, or window you open, all your notes and notebooks are centrally persisted in `~/.notepad-code/notepad-code-data.json`.
- 🤖 **Zero-Config Multi-IDE AI Integration:**
  - **VS Code:** Full GitHub Copilot integration with 11 native Language Model Tools and `@notepad` Chat Participant.
  - **Cursor:** Automatically configured Model Context Protocol (MCP) server for Cursor AI Composer & Chat.
  - **Google Antigravity:** Seamless MCP tools integration and native `.agents/skills/notepad-code` skill.
  - **Windsurf & Claude Desktop:** Auto-detected and registered in their respective global configurations upon activation.
  - **Universal Standalone CLI:** Easily run or connect from any client via `npm run mcp:setup` or `node mcp/server.js`.
- ⚡ **Real-Time Live Disk Sync:** When an external AI agent (Cursor Composer, Antigravity, or Claude) creates, modifies, or deletes a note, your open VS Code webview updates **instantly and automatically** without needing a manual reload.
- 🛡️ **Accidental Data Loss Protection:** Critical operations (`delete_page`, `delete_notebook`, `import_notes`) require explicit confirmation through native VS Code modals or mandatory MCP confirmation flags.
- ✍️ **Clean Plain Text Formatting (No Markdown Clutter):** Smart text normalization ensures notes remain human-readable and clean without unwanted headings or raw markdown fences generated by AI models.
- 🎨 **Minimalist Monochrome Aesthetics:** Designed with pure black (`#000000`) and white (`#FFFFFF`) tones with adaptive VS Code theme variables, offering a distraction-free, high-contrast, eye-friendly editorial experience.
- 🧭 **Sidebar Header Codicon Actions:** Native VS Code Codicon buttons directly in the explorer title bar:
  - `$(new-folder)` New Notebook
  - `$(export)` Export Notes (JSON)
  - `$(cloud-download)` Import Notes (JSON)
- 📌 **Pinning & Live Instant Search:** Pin priority notes to the top of any notebook and filter across all notes in real time.

## 🤖 Multi-IDE & AI Architecture

Users **never need to edit JSON configuration files manually**. When the extension activates, it automatically scans for installed IDEs and registers Notepad Code in their MCP configurations in the background.

```
                  ┌─────────────────────────────────────────┐
                  │   ~/.notepad-code/notepad-code-data.json│
                  │         (Central Data Storage)          │
                  └────────────────────┬────────────────────┘
                                       │
            ┌──────────────────────────┼──────────────────────────┐
            ▼                          ▼                          ▼
     ┌─────────────┐            ┌─────────────┐            ┌─────────────┐
     │   VS Code   │            │   Cursor    │            │ Antigravity │
     │  (Copilot)  │            │  (Composer) │            │  (AI Agent) │
     └─────────────┘            └─────────────┘            └─────────────┘
      Language Model              MCP Server                 MCP Server
       Tools & Chat             (mcp/server.js)            (mcp/server.js)
```

### 1. VS Code (GitHub Copilot)
- Chat directly with your notebooks in the GitHub Copilot Chat panel using `@notepad`:
  - `@notepad /list` — Lists all notebooks and pages.
  - `@notepad /search architecture` — Searches across all notes.
  - `@notepad In "Backend Ideas", create a new page titled "Auth Flow" with JWT notes` — Creates notes with natural language.
- GitHub Copilot can autonomously invoke all 11 native language tools.

### 2. Cursor (AI Composer & Chat)
- Automatically configured at `~/.cursor/mcp.json` and workspace `.cursor/mcp.json`.
- Prompt Cursor Composer to draft code documentation or save debugging insights straight into Notepad Code.

### 3. Google Antigravity
- Automatically registered at `~/.gemini/config/mcp_config.json`.
- Built-in skill definition at `.agents/skills/notepad-code/SKILL.md` ensures agents follow user safety rules and workflows.

### 4. Windsurf & Claude Desktop
- Auto-configured at `~/.codeium/windsurf/mcp_config.json` and `claude_desktop_config.json`.

## 🛠️ Supported Tools (11 Language Model / MCP Tools)

All tools are available across VS Code Copilot and any standard MCP client:

| Tool Name | Description | Safety / Confirmation |
| :--- | :--- | :--- |
| `notepad_list_notebooks` | Lists all notebooks, pages, and IDs. | Safe |
| `notepad_read_page` | Reads full content, title, and stats of a specific page. | Safe |
| `notepad_search_notes` | Keyword search across all notebooks and pages. | Safe |
| `notepad_create_notebook` | Creates a new notebook (`title`, `description`). | Safe |
| `notepad_create_page` | Adds a new clean-text page to a notebook. | Safe |
| `notepad_update_page` | Updates a page title or content. | Safe |
| `notepad_rename_notebook` | Renames an existing notebook. | Safe |
| `notepad_delete_page` | Permanently deletes a specific page. | ⚠️ **User Confirmation Required** |
| `notepad_delete_notebook` | Deletes a notebook and all contained pages. | ⚠️ **User Confirmation Required** |
| `notepad_export_notes` | Exports all notebooks and pages as a JSON string. | Safe |
| `notepad_import_notes` | Imports and restores notebooks from a JSON backup. | ⚠️ **User Confirmation Required** |

## 🛡️ Data Loss Prevention Mechanism

To protect against inadvertent note deletion by AI agents:

1. **VS Code Copilot (Native Prepare Invocation):**
   - Destructive actions trigger a native VS Code confirmation prompt showing the target notebook/page details. The agent cannot proceed until the user explicitly clicks **"Continue"**.
2. **MCP Server (Explicit Confirmation Flag):**
   - `notepad_delete_page`, `notepad_delete_notebook`, and `notepad_import_notes` require `confirm: true`. Without this flag, the server rejects the action and prompts the agent to ask for explicit user consent.

## 📂 Where are Notes Stored?

All data is stored locally on your machine in standard JSON:
* **macOS / Linux:** `~/.notepad-code/notepad-code-data.json`
* **Windows:** `C:\Users\<Username>\.notepad-code\notepad-code-data.json`

Your notes never leave your computer and are completely private and offline.

## 🚀 Development & Build

### Prerequisites
- Node.js (v18+)
- Visual Studio Code (v1.85+) or Cursor

### Commands
```bash
# Install dependencies
npm install

# Type check with TypeScript
npm run typecheck

# Build production bundle with esbuild
npm run compile

# Watch mode for rapid development
npm run watch

# Package into a VSIX extension bundle
npm run package

# Automatically configure MCP in all installed IDEs
npm run mcp:setup
```

### Debugging (F5)
1. Open the project directory in VS Code or Cursor.
2. Press `F5` to start the **Extension Development Host**.
3. Click the **Notepad Code** icon in the Activity Bar to begin taking notes.
